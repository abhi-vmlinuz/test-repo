# ZecurX LABS - CTF Platform Overview

## What is a CTF?

**CTF (Capture The Flag)** is a cybersecurity competition where participants solve security-related challenges to find hidden "flags" - special text strings that prove you solved the challenge.

Think of it like a treasure hunt, but for hackers!

---

## How ZecurX LABS CTF Works

### The Basics:
1. **Browse Challenges** - Pick a challenge from the list
2. **Read the Description** - Understand what you need to do
3. **Solve the Puzzle** - Use your hacking skills
4. **Find the Flag** - Usually in format `CTF{something_here}`
5. **Submit the Flag** - Enter it to earn points
6. **Compete on Leaderboard** - See how you rank against others

---

## Challenge Categories

### 🌐 Web Exploitation
Challenges involving website vulnerabilities:
- SQL Injection - Manipulating database queries
- XSS (Cross-Site Scripting) - Injecting malicious scripts
- Authentication bypass - Breaking login systems
- Cookie manipulation - Attacking session management

### 🔐 Cryptography
Challenges involving codes and ciphers:
- Classical ciphers (Caesar, Vigenère)
- Modern encryption (RSA, AES)
- Hash cracking
- Encoding/decoding

### 🔍 Forensics
Challenges involving investigation:
- File analysis - Finding hidden data
- Memory dumps - Extracting information
- Metadata analysis - Hidden info in files
- Log analysis - Finding clues in logs

### 💻 Binary Exploitation
Challenges involving programs:
- Buffer overflow - Memory corruption
- Format string - Exploiting print functions
- Reverse engineering - Understanding code

### 💡 General Skills
Basic skills needed for CTF:
- Linux commands
- Scripting basics
- Using common tools
- Research skills

## Scoring System

### Earning Points:
- **Solve Challenges** - Main way to earn points
- Each challenge has fixed points based on difficulty

### Losing Points:
- **Using Hints** - Each hint costs 5-40 points
- Points deducted when you unlock a hint
- Even if you solve the challenge later

### Preventing Abuse:
- Can't solve same challenge twice
- Points only awarded once per challenge
- Hints can only be unlocked once

---

## Hints System

When you're stuck, you can unlock hints:

1. **Click hint button** - See the cost
2. **Confirm unlock** - Points deducted
3. **View hint** - Gets you closer to solving
4. **Multiple hints** - Usually 2-3 per challenge
5. **Each hint costs more** - First is cheap, later ones expensive

**Strategy tip:** Try harder before using hints - they cost points!

## Flag Format

All flags follow this format:
```
CTF{some_text_here}
```

Examples:
- `CTF{hello_world}`
- `CTF{sql_1nj3ct10n_m4st3r}`
- `CTF{g00d_j0b_h4ck3r}`

**Tips:**
- Case sensitive (usually)
- Copy exactly, including CTF{}
- No spaces before or after
- Sometimes lowercase, sometimes mixed

## Getting Help

If you're stuck:
1. Re-read the challenge description
2. Search online for the technique
3. Try the hints (costs points)
4. Take a break and come back
5. Ask the community (after the CTF)
